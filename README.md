## Project Description
This project was developed for the Front-End Development course and focuses on building user-friendly web forms, structuring layouts with Bootstrap 5 grid components, and implementing comprehensive form validation (both native HTML5 and Bootstrap styles).

## Project Structure
- `index.html` — Part 1: Basic contact form featuring native HTML5 validation attributes (`required`, input types, length limits).
- `bootstrap.html` — Part 2: Contact form styled with Bootstrap 5 components, helper text, and validation feedback states (`valid-feedback` / `invalid-feedback`).
- `register.html` — Part 3: Fully responsive advanced registration form using Bootstrap Grid, including input controls (`select`, `checkbox`, `radio`), and JavaScript-based password confirmation matching.
